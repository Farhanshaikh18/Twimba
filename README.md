# Twimba
A responsive Twitter (X) frontend clone built to strengthen my skills in HTML, CSS, and JavaScript. This project recreates the core user interface of Twitter, focusing on modern layout techniques, responsive design, and interactive user experiences.

The goal of this project was to practice real-world frontend development concepts such as component structuring, DOM manipulation, event handling, styling, and responsive web design while replicating a popular social media platform.
